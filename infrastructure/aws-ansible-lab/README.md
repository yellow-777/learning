# AWS Ansible Infrastructure Lab

AWS上にLinux検証環境を構築し、ネットワーク・Linux・Ansible・Apacheの
基本的な構築および動作確認を行う学習ポートフォリオ。

## 学習対象

- AWS VPC
- Subnet
- Route Table
- Internet Gateway
- Security Group
- EC2
- Linux
- SSH
- Ansible
- Apache (httpd)
- Git / GitHub

## 方針

AWS上の検証環境は学習後に削除する。
構成、コマンド、検証結果、トラブルシューティングはGitHubへ記録する。

## Environment

- Local: WSL2 / Ubuntu 24.04 LTS
- Cloud: AWS
- Version Control: Git / GitHub
